# USS v0.1 — Hermes Handoff Package

**Prepared:** 2026-10-13. **Status:** draft-only, not a normative release.

This archive contains 14 draft technical standards, the ratified decision ledger (16 decisions), SSOT/governance boundaries, proposed token budgets, a controlled implementation plan, templates and a ready-to-use Hermes start prompt.

## Quick start
1. Extract to a temporary workspace.
2. Read `PROMPT_FOR_HERMES.md` and send its content to Hermes with this folder available.
3. Ask Hermes to begin with read-only discovery; do not authorize repository changes or normative release by implication.
4. Review `governance/DEFAULTS_AND_TOKEN_BUDGETS.md` separately: numbers are proposals.
